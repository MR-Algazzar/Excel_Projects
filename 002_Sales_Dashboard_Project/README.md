# 📊 Sales Dashboard Project

An advanced, interactive Excel sales dashboard built to track key performance indicators, analyze regional sales trends, evaluate product performance, and deliver actionable business intelligence.

---

## 🚀 Project Overview

This project transforms raw transactional sales data into a clean, dynamic, and executive-ready dashboard. It is designed to empower stakeholders with real-time insights into revenue generation, top-performing categories, customer demographics, and regional growth opportunities through advanced Excel formulas, pivot tables, and interactive data visualization techniques.

## 🛠️ Tools, Functions & Features Used

* **Microsoft Excel**: Core platform for data modeling, cleaning, analysis, and dashboard layout.
* **Data Cleaning & Preparation**: Removing duplicates, handling missing values, standardizing date formats, and structuring flat files into relational tables.
* **Advanced Formulas & Functions**:
* `XLOOKUP` / `VLOOKUP` for cross-sheet data retrieval.
* Conditional aggregations (`SUMIFS`, `AVERAGEIFS`, `COUNTIFS`).
* Logical and text functions (`IF`, `IFS`, `CONCATENATE`).


* **Pivot Tables & Pivot Charts**: Dynamic slicing and dicing of sales figures by region, category, time period, and sales representative.
* **Interactive Slicers**: Connected slicers to filter multiple charts and pivot tables simultaneously with a single click.
* **Dynamic Visualizations**: Custom bar charts, line graphs, donut charts, and KPI summary cards.

---

## 📂 Dataset Structure

The workbook is structured into organized worksheets:

1. **Data Source / Raw Data**: The cleaned transactional database containing order IDs, dates, customer details, product categories, quantities, unit prices, revenues, and profit margins.
2. **Pivot Cache / Calculations**: Intermediate summary tables powering the dashboard metrics.
3. **Dashboard**: The main interactive interface presenting high-level KPIs and visual charts.

## 📈 Key Insights & Business Recommendations

* **Revenue Drivers**: Identified top-performing product categories that contribute to the majority of overall profits, allowing management to optimize inventory allocation.
* **Regional Opportunities**: Highlighted high-performing regions vs. underperforming areas, providing a clear roadmap for targeted marketing campaigns.
* **Seasonality Trends**: Observed peak sales months, enabling proactive staffing and stock planning ahead of high-demand periods.

## ⚙️ How to Use

1. Download the `003_Sales_Dashboard_Project.xlsx` file from this repository.
2. Open the file in **Microsoft Excel** (Excel 2016 or newer recommended for full compatibility with modern formulas and slicers).
3. Use the interactive slicers on the **Dashboard** sheet to filter and explore data across different dimensions.
